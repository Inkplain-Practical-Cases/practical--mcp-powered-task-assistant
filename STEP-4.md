# Step 4 of 6 — Invoke tools and validate results
## What you build in this step
A safe MCP client invocation path: discover → validate JSON Schema → call_tool → reject isError → parse structured results.
## What you learn
- MCP tool arguments are untrusted, even when generated by an LLM
- Discover and validate against the server's live inputSchema
- Distinguish transport, validation and business failures
## What changed since step 3
Four new components implement validated client-side tool execution.

```bash

python -m pytest -q
python -m app.client.invoke_cli
```
